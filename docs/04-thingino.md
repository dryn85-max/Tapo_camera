# 4. Путь 3: открытая прошивка Thingino

Thingino (https://thingino.com, https://github.com/themactep/thingino-firmware)
это открытая прошивка для камер на чипах Ingenic. После неё камера становится
обычной ONVIF/RTSP-камерой с веб-интерфейсом, без каких-либо аккаунтов, и
адоптится в Protect как любая сторонняя камера. Есть подтверждённые случаи
адопта Thingino-камер в Protect, но есть и отчёты о циклах переподключения,
поэтому это путь для энтузиастов, а не замена путям 1 и 2.

## 4.1. Главное: Tapo C200 выпускался на разных чипах

| Ревизия (наклейка на дне) | SoC | Открытая прошивка |
|---------------------------|-----|-------------------|
| C200 V1 | Realtek RTS3903 | Нет. Известен root-пароль `slprealtek` и стоп-слово U-Boot `slp`, можно получить консоль, но готовой прошивки нет |
| C200 V2 | Realtek RTS3903N | Нет |
| C200 V5 / 5.0 (ЕС, 2024+), C200C | Ingenic T23N + сенсор SC2336P, Wi-Fi RTL8188FTV или WQ9001, flash 8 МБ | **Thingino, официально поддержан**, но см. 4.1a |
| C200 (ревизия, совпадающая с TC70) | Ingenic T31L + SC2336 + RTL8188FTV, 8 МБ flash | **Thingino, профиль TC70** |

TP-Link не публикует соответствие «версия на наклейке → чип», в разных
странах оно отличается. Для ЕС-ревизии 5.0 чип подтверждён несколькими независимыми отчётами
(T23N). Для других наклеек точно узнать чип можно, сняв крышку и прочитав
маркировку на самой большой микросхеме (`T23N`, `T31L`, `RTS3903`).

## 4.1a. Ваша ревизия: Tapo C200(DE) Ver 5.0 (ЕС, партия 2024)

Это ревизия на **Ingenic T23N**, сенсор SmartSens SC2336P, Wi-Fi Realtek
RTL8188FTV (у варианта C200C встречается WQ9001), NOR-flash 8 МБ, ядро
Linux 3.10.14 Ingenic. Образ Thingino для неё существует:
`tplink_tapo_c200_t23n_sc2336p_rtl8188ftv`, модель переведена в «supported»
в релизе от ноября 2025. Но на октябрь 2026 ситуация такая:

| Что | Состояние |
|-----|-----------|
| Видео, Wi-Fi, ИК-подсветка, фильтр, microSD | Работают (отчёт по C200C EU/5.0) |
| PTZ (SPI-моторы) | Две регрессии, обе исправлены: апрель 2026 (веб-интерфейс) и август 2026 (параметры `invert_x`) |
| Сборка под 8 МБ flash | **Открытый баг #1840 (20 окт 2026)**: SD-карта не включается на уровне ядра, data-раздел 256 КБ меньше минимума JFFS2, overlay не монтируется, ФС только для чтения. Автор отчёта: без UART сборка «функционально непригодна» |
| Установка с SD-карты | Не работает на заводской прошивке: `autoupdate-full.bin` нужен уже установленный загрузчик Thingino |
| UART | На EU Rev.5 тестовые площадки **не соединены с процессором**: TP-Link не запаивает два нулевых резистора на линиях RX/TX. Нужно их напаять (0402/0603), после чего доступны U-Boot и консоль. Описано в разборе Квентина Кайзера (июль 2025) |
| USB-режим Ingenic (thingino-dfu / Web Flasher) | T23 поддержан инструментом, но для C200 нет описания, как войти в USB boot mode и где USB-линии на плате |
| CH341A с прищепкой SOIC8 | Рабочий путь по отчёту от августа 2026 («clip-based flashing»). Нюанс: прищепка может запитать SoC, и чтение сорвётся, тогда чип придётся выпаивать |

**Вывод для C200 V5:** прошивка технически доступна, но сейчас требует
пайки (резисторы UART или выпаивание flash) и живёт с открытым багом
корневой ФС. Разумно отложить до закрытия #1840 и использовать пути 1 и 2.
Если всё же делать: сначала полный дамп flash через CH341A или
`thingino-dfu -r backup.bin`, только потом запись.

Дополнительно: камера только Wi-Fi, Ethernet-порта нет (так написано на
коробке), поэтому для Protect она в любом случае будет беспроводной
сторонней камерой.

## 4.2. Что потребуется для Ingenic-ревизии

- UART-переходник 3,3 В (CP2102 / CH340), пайка на 3 контакта платы.
- Образ Thingino под точную связку SoC + сенсор + Wi-Fi-модуль (из списка
  камер на сайте проекта или из релизов на GitHub).
- Обязательно сделать **полный бэкап flash** из U-Boot перед прошивкой:
  откатиться на TP-Link после перезаписи без бэкапа будет нельзя.
- Последовательность: прервать U-Boot по UART → загрузить образ по TFTP →
  записать в flash → перезагрузка → настроить Wi-Fi и пароль в веб-интерфейсе
  Thingino → включить ONVIF (включён по умолчанию) → адопт в Protect по
  пути 1.

## 4.3. Что даёт и что теряется

Плюсы: никакого облака и приложения Tapo, обновления независимо от TP-Link,
RTSP/ONVIF/WebRTC/MQTT, детекция движения, работающий PTZ по ONVIF.

Минусы: ручная пайка, риск «кирпича», нет гарантии, качество ISP-настроек
хуже заводских (цвета, ночной режим), SD-запись и часть функций могут
требовать доводки под конкретную плату.

## 4.4. Почему не «своя» прошивка с нуля

Даже Thingino не пишет драйверы сенсора и кодека сам: он использует закрытые
бинарные библиотеки Ingenic (libimp) поверх открытого ядра. Для Realtek
RTS3903 таких библиотек в открытом доступе нет, есть только GPL-архив
TP-Link с ядром без ISP-части. Поэтому собственная прошивка под
Realtek-ревизии C200 практически невыполнима.
