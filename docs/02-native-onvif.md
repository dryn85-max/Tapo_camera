# 2. Путь 1: нативный ONVIF в UniFi Protect

Требуется UniFi Protect **5.0.33 или новее** (на UDM, UCG, UNVR и т. п.).
Начиная с Protect 7.2 поддержка сторонних камер расширена (события движения,
PTZ на части моделей, аудио с транскодированием).

## 2.1. Включить обнаружение сторонних камер

1. Protect → Settings → System → Advanced (в новых версиях: Settings →
   Camera → Third-Party Cameras) → включить **Discover Third-Party Cameras**
   (ONVIF).
2. На странице UniFi Devices (или Protect → Devices) появится найденная
   камера с типом «Third-Party». Если не появилась, нажать «Add Device» и
   ввести IP камеры вручную (вариант «Add via IP»).
3. При адопте ввести **аккаунт камеры** из приложения Tapo (не TP-Link ID).
   Protect не принимает пустой пароль.

## 2.2. Что должно получиться

- В Protect камера видна как «Tapo C200», HQ = `stream1` (1920×1080, 25 к/с),
  LQ = `stream2` (1280×720, 25 к/с), оба H.264 High. Protect берёт ровно один HQ и один LQ поток,
  C200 это как раз даёт.
- Запись постоянная и по движению (события приходят по ONVIF events).
- Playback и таймлайн работают. Scrubbing зависит от ключевых кадров,
  у Tapo интервал I-frame обычно 2 с, этого достаточно.

## 2.3. Типовые проблемы

| Симптом | Причина | Что делать |
|---------|---------|-----------|
| Камера не находится | WS-Discovery не проходит через VLAN | Добавить по IP вручную или временно поставить консоль в VLAN камер |
| «Authority failure» / 401 | Часы камеры и консоли разошлись | NTP для камер, см. [01-camera-prep.md](01-camera-prep.md#12-сеть-в-unifi) |
| Адопт проходит, но чёрный экран | Исчерпан лимит RTSP-сессий камеры | Закрыть приложение Tapo и другие клиенты; если нужно несколько потребителей, перейти на [мост](03-bridge.md) |
| Поток рвётся каждые несколько секунд | Protect не договорился по ONVIF Media профилю | [Мост](03-bridge.md): Protect будет говорить с rtsp-to-onvif, а не с Tapo |
| Нет аудио | Ограничение Protect для сторонних камер | Смириться или ждать новых версий Protect |

## 2.4. После адопта

Приложение Tapo по-прежнему может показывать камеру **локально** (телефон в
той же сети), но при заблокированном интернете вход в приложение потребует
кэшированной сессии. Для повседневного просмотра используйте приложение
UniFi Protect.
