# 0. Железо: UniFi Dream Router 7 (UDR7) и две Tapo C200

## 0.1. Почему UDR7 подходит

- Роутер, коммутатор, точка доступа Wi-Fi 7 (2.4 / 5 / 6 ГГц) и UniFi Protect
  в одном корпусе. Для двух Wi-Fi-камер ничего докупать не нужно.
- Protect на UDR7 поддерживает сторонние ONVIF-камеры так же, как на любой
  консоли с Protect 5.0.33+ (функция программная, см. [02-native-onvif.md](02-native-onvif.md)).
- Лимит Protect на UDR7: до 5 HD-камер, или 2 камеры 2K, или 1 камера 4K.
  Tapo C200 это 1080p (HD), две камеры занимают 2 слота из 5.

## 0.2. Хранилище: microSD

В комплекте карта 64 ГБ. Две C200 при ~2 Мбит/с на поток пишут около
1.8 ГБ в час суммарно, то есть 64 ГБ хватит примерно на полтора суток
непрерывной записи. Варианты:

| Режим записи | Карта | Глубина архива |
|--------------|-------|----------------|
| Только по движению | 64 ГБ (в комплекте) | недели, зависит от активности |
| Непрерывно, 2 камеры | 256 ГБ | ~6 суток |
| Непрерывно, 2 камеры | 512 ГБ | ~12 суток |
| Непрерывно, 2 камеры | 1 ТБ | ~24 суток |

Брать карту класса High Endurance (для видеорегистраторов), обычные карты
быстро умирают от постоянной записи. Карту можно заменить позже без
переустановки: Protect предложит отформатировать новую.

## 0.3. Схема подключения

```
Интернет (ONT / роутер Digi в режиме bridge)
        │
   WAN 2.5G
        │
   ┌────┴────┐  Wi-Fi 2.4 ГГц ──── Tapo C200 #1 (Fixed IP)
   │  UDR7   │  Wi-Fi 2.4 ГГц ──── Tapo C200 #2 (Fixed IP)
   │ Protect │
   └────┬────┘  LAN 2.5G (PoE) ─── (свободен, например для будущей UniFi-камеры)
        │
   LAN 2.5G ─── компьютер / Docker-хост для моста, если он понадобится
```

Если роутер Digi нельзя перевести в bridge, UDR7 ставится за ним с двойным
NAT. На камеры и Protect это не влияет: всё локально.

## 0.4. Порядок после покупки

1. Настроить UDR7 (приложение UniFi), создать Wi-Fi. Для камер удобнее
   отдельный SSID только на 2.4 ГГц, без band steering: Tapo C200 не видит
   5 ГГц и иногда не находит объединённые сети.
2. Сбросить обе C200 и добавить их в приложении Tapo в этот SSID
   ([01-camera-prep.md](01-camera-prep.md), раздел 1.0). На время добавления
   камерам нужен интернет.
3. В приложении Tapo создать Аккаунт камеры на каждой.
4. UniFi Network → Client Devices → камерам Fixed IP.
5. Protect → включить Discover Third-Party Cameras → адоптировать обе
   ([02-native-onvif.md](02-native-onvif.md)).
6. Проверить запись и события, затем закрыть камерам интернет правилом с
   исключением для NTP ([01-camera-prep.md](01-camera-prep.md), раздел 1.2).

## 0.5. Если понадобится мост

UDR7 не запускает Docker. Для моста из [03-bridge.md](03-bridge.md) нужен
отдельный хост: мини-ПК, Raspberry Pi 4 или NAS, подключённый кабелем в LAN
UDR7. Для двух камер и нативного адопта он скорее всего не потребуется.

## 0.6. Опционально

- **AI Port**: распознавание людей, машин, лиц на сторонних камерах.
  Докупается позже, если захочется умных уведомлений.
- **Карта microSD 512 ГБ+**: если нужна непрерывная запись.
