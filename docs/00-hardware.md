# 0. Железо: UniFi Cloud Gateway Industrial и две Tapo C200

## 0.1. Что умеет UCG-Industrial из нужного

- Роутер, коммутатор с PoE, точка доступа Wi-Fi 7 (2.4 и 5 ГГц, две внешние
  антенны) и UniFi Protect в одном безвентиляторном корпусе.
- Protect поддерживает сторонние ONVIF-камеры так же, как на любой консоли
  с Protect 5.0.33+ (функция программная, см. [02-native-onvif.md](02-native-onvif.md)).
- Лимит Protect: до 15 HD-камер, или 8 камер 2K, или 5 камер 4K. Две
  Tapo C200 (1080p) занимают 2 слота из 15.
- Процессор Cortex-A73 2.2 ГГц: запас по IDS/IPS и Protect большой, для
  двух камер нагрузка незаметна.

Избыточно для квартиры: бюджет PoE 270 Вт, порты 10GbE, крепление на
DIN-рейку. На работу с камерами это не влияет.

## 0.2. Хранилище: microSD

В комплекте карта 128 ГБ, слота для SSD нет. Две C200 на 25 к/с при
непрерывной записи дают около 2.5 ГБ в час, при записи по движению в
квартире обычно 1–3 ГБ в сутки.

| Режим записи | Карта | Глубина архива |
|--------------|-------|----------------|
| Только по движению (выбрано) | 128 ГБ (в комплекте) | недели |
| Непрерывно, 2 камеры | 128 ГБ | ~2 суток |
| Непрерывно, 2 камеры | 512 ГБ | ~8 суток |
| Непрерывно, 2 камеры | 1 ТБ | ~17 суток |

Если когда-нибудь понадобится непрерывная запись, брать карту класса
High Endurance. Замена карты без переустановки: Protect предложит
отформатировать новую.

## 0.3. Схема подключения

```
Интернет (ONT / роутер Digi в режиме bridge)
        │
   WAN (2.5G или 10G)
        │
   ┌────┴──────────┐  Wi-Fi 2.4 ГГц ──── Tapo C200 #1 (Fixed IP)
   │ UCG-Industrial│  Wi-Fi 2.4 ГГц ──── Tapo C200 #2 (Fixed IP)
   │   Protect     │
   └────┬──────────┘  LAN PoE ─── свободны (будущие проводные камеры UniFi, точка доступа)
        │
   LAN ─── компьютер / Docker-хост для моста, если он понадобится
```

Если роутер Digi нельзя перевести в bridge, UCG-Industrial ставится за ним
с двойным NAT. На камеры и Protect это не влияет: всё локально.

Размещение: Wi-Fi встроен в шлюз, поэтому он должен стоять там, где нужно
покрытие, антенны вертикально. Если покрытия не хватит, в любой PoE-порт
включается точка доступа UniFi без инжектора.

## 0.4. Порядок после распаковки

1. Настроить шлюз (приложение UniFi), создать Wi-Fi. Для камер удобнее
   отдельный SSID только на 2.4 ГГц, без band steering: Tapo C200 не видит
   5 ГГц и иногда не находит объединённые сети.
2. Сбросить обе C200 и добавить их в приложении Tapo в этот SSID
   ([01-camera-prep.md](01-camera-prep.md), раздел 1.0). На время добавления
   камерам нужен интернет.
3. В приложении Tapo на каждой камере: аккаунт камеры (одинаковый на обеих),
   Full HD, 25 к/с, обнаружение движения включено, звук выключен.
4. UniFi Network → Client Devices → камерам Fixed IP.
5. Protect → включить Discover Third-Party Cameras → адоптировать обе,
   режим записи Detections ([02-native-onvif.md](02-native-onvif.md)).
6. Проверить запись по движению, затем закрыть камерам интернет правилом с
   исключением для NTP ([01-camera-prep.md](01-camera-prep.md), раздел 1.2).

## 0.5. Если понадобится мост

UCG-Industrial не запускает Docker. Для моста из [03-bridge.md](03-bridge.md)
нужен отдельный хост: мини-ПК, Raspberry Pi 4 или NAS, подключённый кабелем
в LAN шлюза. Для двух камер и нативного адопта он скорее всего не потребуется.

## 0.6. Опционально

- **AI Port**: распознавание людей, машин, лиц на сторонних камерах в Protect.
  Распознавание людей внутри Tapo в Protect не передаётся.
- **Карта microSD 512 ГБ+**: только если понадобится непрерывная запись.
